# Infinity Telecom — Smart Functions Edition

এই সংস্করণটি Final V4-এর UI অপরিবর্তিত রেখে শুধু নির্বাচিত ফাংশন যোগ করে তৈরি করা হয়েছে।

যোগ হয়েছে:
- Customer Summary
- Daily Counter
- Telegram Status
- Offline Queue
- Amount Color
- Smart Search
- Daily Telegram Report
- Keyboard Mode (F2/F3/F4 এবং service menu-তে 1–4)

আগের Firebase ও Render Environment Variables একই থাকবে।

## Infinity Accounts (Added)
- Accounts button in top navigation
- Personal Receive / Agent Cash Out / Cash In / Send Money / Recharge / Transfer / Expense / Adjustment
- Profit = customer charge - own cost
- Opening cash, expected cash, actual cash and difference checking
- Day Close text report and daily CSV export
- Existing successful app transactions are added automatically with zero profit; add charge/cost as a separate ledger entry when needed.
- Accounts data is stored per logged-in user in this browser's localStorage.
